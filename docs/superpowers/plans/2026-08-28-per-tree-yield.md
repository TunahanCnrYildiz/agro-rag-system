# Per-Tree Fruit Yield (Budget Form) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve TÜİK's published `kg/ağaç` figure as the budget form's yield prefill for tree crops, instead of a `kg/da` figure derived from a denominator that counts a different population than its numerator.

**Architecture:** The builder already reads `verim_agac` as the density gate's evidence and discards it; it will now also write it as a `yield_kg_tree` measure. `src/norms.py` loads that measure as OPTIONAL (field crops do not have one) and resolves it with the existing `_pick`. `src/budget.py` gains a `tree_count` field and a `kg_agac` unit on `yield_total`, mirroring the existing `per_area` mechanism exactly. `compute()` and the client are untouched.

**Tech Stack:** Python 3.14, pytest, no new dependencies. Data file `data/crop_norms.json`, regenerated by `python -m scripts.build_crop_norms`.

**Spec:** `docs/superpowers/specs/2026-08-28-per-tree-yield-design.md`

## Global Constraints

- Run every command from the repo root. `src/config.py` reads a RELATIVE `env_file=".env"`; running elsewhere silently loads a wrong `EMBEDDING_MODEL`.
- Turkish user-facing strings only, matching the existing voice. Never claim to be a licensed Ziraat Mühendisi.
- **A missing norm is never zero.** Absence returns `None` throughout; a zero flows into the budget arithmetic and comes out as a confident wrong answer.
- **No gate, bound, or threshold may be applied to the published per-tree figure.** Every existing gate defends a denominator this project chose; a published figure has none.
- Commit messages: short, natural, English, no `Co-Authored-By` trailer.
- `python -m pytest -q` must be green (930 tests at plan time) before every commit.
- Console output in scripts goes through `scripts._console.use_utf8_console()`; on Windows a bare `print` of Turkish text raises `UnicodeEncodeError`.

```python
    trees_spec = _FIELDS_BY_ID["tree_count"]
    trees_value, trees_error = _read(trees_spec, raw, area_da)
    values[trees_spec.id] = trees_value
    if trees_error is not None:
        errors.append(trees_error)
    trees = trees_value.amount if trees_value is not None else None

    for spec in FIELDS:
        if spec.id in (area_spec.id, trees_spec.id):
            continue
        value, error = _read(spec, raw, area_da, trees)
        values[spec.id] = value
        if error is not None:
            errors.append(error)
```

```python
def _yield_cell(row) -> tuple[dict | None, str]:
    """This row's yield cell, and which measure it came from.

    A row is served PER TREE exactly when its `yield_kg_tree` resolved - no
    list of crops, no flag, no name matching. TUIK publishes no per-dekar yield
    for 61 tree crops, and the kg/da this project derives for them divides a
    province's whole production by the few dekars of COMPACT orchard it
    records; the published per-tree figure has no such denominator. So per-tree
    wins wherever it exists, which is the same precedence the builder already
    applies in the other direction.

    Returns the measure name too, so _verify checks a claim against the very
    cell that was served rather than guessing which one it was.
    """
    if row.yield_kg_tree is not None:
        return (_norm_cell(row.yield_kg_tree, *_NORM_UNITS["yield_tree"], None,
                           show_range=True),
                "yield_kg_tree")
    return (_norm_cell(row.yield_kg_da, *_NORM_UNITS["yield"], None,
                       show_range=True),
            "yield_kg_da")
```
